# Sandbox

This directory contains experimental email markup, prototype HTML files, and exploratory layouts.

These files are used for visual testing and experiments prior to being broken down into Lit-HTML template sections.
They are **not** production templates and should not be directly imported into the rendering pipeline.

## Contents

| File | Description |
|---|---|
| `eyes.html` | Exploratory eye-tracking / visual hierarchy email markup experiment |
| `google.html` | Raw HTML email prototype |
